# 演示能力与实验成果

实验围绕四项能力组织：保留原算法、增加眼嘴视觉分类、解释多模型判决、复用原模型实现边缘运行。

## 可演示内容

| 演示 | 使用入口 | 展示对象 |
|---|---|---|
| 原座舱与小瑞 | Windows ui/run_ui.bat，或已配置Linux入口 | 原设计语言、导航、多媒体与语音入口 |
| 真实摄像头推理 | 驾驶监测页点击连接 | 同源人体/面部、模型状态与真实等级 |
| 五组融合解释 | 原监测详情与多模型区域 | Eye/Mouth/Head/Transformer/FaceBranch、冲突和热身 |
| Legacy/V2对照 | 后端开放时的模式选择 | ACK后生效；等级变化与原因，而非切换动画 |
| ARM64横屏 | 已部署K1-MINI X11桌面 | 1280×800逻辑视口、Goodix触摸及重启持久化 |

板端新一轮演示前先确认散热。当前长时整机验收未完成，不能以重复旧状态代替实时推理。纯demo模式应显式标注“界面演示”。

## V2与Legacy真实分布

| 模式 | L0 | L1 | L2 | L3 | 等级切换次数 |
|---|---:|---:|---:|---:|---:|
| Legacy | 69 | 152 | 0 | 442 | 11 |
| Fusion V2 | 327 | 39 | 232 | 65 | 22 |

同一YawDD参与者样本，2741源帧，首个决策后覆盖88.27秒，511/663决策等级不同。该实验展示融合策略如何改变证据解释与等级分配。没有逐帧风险真值，差异率不是错误率，不能据此说V2更准确或更稳定。误报率、漏报率、检测延迟保留未评估。

MRL按参与者选取子集；公开checkpoint训练集与其重叠未知。YawDD嘴部回放为定性验证，说话/大笑/唱歌需要独立标签；NITYMED尚未取得。后续按参与者或视频划分，不把相邻帧随机切分作独立泛化证据。
