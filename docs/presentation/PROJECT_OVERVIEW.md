# 项目总体介绍

## 背景与目标

驾驶员疲劳同时体现在动作时间变化、眼睑闭合、嘴部状态与头部姿态。灵途智行将这些观测尺度组织为多模型证据，面向智能座舱提供可解释的风险判断及亲和的交互反馈。

项目定位：**面向智能座舱的多模型融合驾驶员状态感知与情感化交互系统**。感知目标为疲劳与相关异常状态；当前Transformer实际为normal/fatigue二分类，不能将全部驾驶行为名称解释成独立识别类别。

## 方案与技术路线

单目UVC摄像头采集同源图像，PoseLandmarker提取身体关键点，原Transformer建模45帧姿态序列；FaceLandmarker提供面部几何、头姿与滚动统计。YOLO Eye/Mouth复用同一面部点集裁剪ROI，提供局部外观分类。原LR与Legacy继续保留，Fusion V2将眼、嘴、头姿、Transformer和FaceBranch组织为五组证据。

决策层输出L0–L3及原因，原WebSocket驱动驾驶监测、小瑞、语音、导航和多媒体。系统保留影子对照、运行时模式确认、失效状态与数值对拍，为工程迭代提供复核路径。

## 三类贡献

| 方向 | 实现贡献 | 直接价值 |
|---|---|---|
| 算法 | 身体时序+面部几何+ROI分类，相关证据分组 | 将单一特征扩展为可解释多模型共识 |
| 系统 | 感知、融合、状态传输、座舱反馈闭环 | 同一真实等级和原因贯穿视觉与交互 |
| 工程 | PC回归、ARM64依赖审计、五模型上板、横屏触摸及独立预览 | 支撑单主控边缘运行与可复现验收 |

## 应用场景

智能座舱驾驶员状态展示、分层疲劳提示、实验室人机交互原型、边缘视觉系统教学与技术交流。视觉推理可本地CPU运行；导航和在线对话按配置依赖网络服务。

当前成果以[实验数据](DEMO_AND_EXPERIMENTS.md)支撑，工程验收以[部署状态](../DEPLOYMENT_STATUS.md)为准。小瑞与原座舱设计体现项目的情感化表达，不将系统定位为普通Web管理后台。
