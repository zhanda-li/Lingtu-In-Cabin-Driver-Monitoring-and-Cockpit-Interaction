UI 设计规范

色板

抄的是 style.css 里的现值，不是设计稿上的理想值
**整个主题只有一个变量**：`--accent`（原色）和它的数字分身 `--rgb` —— 后者是给 `rgba()` 用的，因为 CSS 变量不能塞进颜色函数里拆。四档状态只改这两个值， 卡片、光带、呼吸光、图表线、药丸、外发光**全部继承**，所以"换档变色"是一处改动， 不会出现"红色模式漏改了某个角"。

  • 小瑞手写体"KaiTi" → "STKaiti" → "Segoe Script" → cursive（只有 .xq-note 和 .rec-tip 用）

全站一张 .card 配方

  • backgroundrgba(9,24,36,.52)（--glass）—— 半透明是前提，不透明就没什么可糊的了
  • backdropblur(16px) saturate(1.25) —— 顺带把背后的颜色饱和一点，不然糊完发灰
  • border1px solid rgba(255,255,255,.10)（--line）
  • shadow0 1.2rem 3rem rgba(0,0,0,.42) + inset 0 1px 0 rgba(255,255,255,.05)，外面压暗、上沿留一道高光

  • 注意卡的描边是**固定白 10%**，不跟 --accent 走 —— 换档时卡片本身不变色，只有嵌在里面的发光元素变色

一个页面只有一个 `body`，所以并排看四档不能靠 `body[data-sev]` —— 本页是靠页内 `<style>` 里那四条 `.sev-s[data-sev]` 把变量**复制到每个样本容器**上， 这四行与 style.css 必须手工保持一致。 2026-09-24 起那 6 处硬编码全部收进变量了（疲劳概率条的渐变、 时间线圆点上的四色 ::after、指标小格的按档着色文字），所以现在四档色一共只有 **两个出处**：style.css 的 `:root` 一套（深色）、`html[data-theme="light"]` 一套（浅色）。 要改色改那两个块就够，不用再满库找了。
为什么这四格就是 `severity`：「只做疲劳」之后全站只剩一条轴 —— 后端 `ui/state.py` 的 `severity` 只有 normal/mild/moderate/severe 四个值， 配色、大标题、小瑞的表情和话、语音语气全跟它走。支路一自己那三个**类别** （normal/phone/fatigue）不再直接决定颜色：它只在概率条和「低头/点头」这行 行为说明里露面，`phone` 和 `fatigue` 都落在**重度**这一档。
