# ⚠️ 跟 requirements-asr.txt 一样，这一份**故意不并进仓库根目录的
#    requirements.txt**：
#   1. 不装它界面照常能用 —— 主路是**浏览器**的 speechSynthesis，那一批中文
#      神经音色是 Edge 白送的，零安装零 key。这一份装的是**服务端那条备路**

#
# 装法**不是** `pip install -r`，是双击 ui\install_tts.bat。那个 bat 走的是
# "先快照环境 → 装 → 再快照 → 比对"，和 install_asr.bat 一个套路。
#
# ✅ 这一份**没有 numpy 风险**（这是它和 requirements-asr.txt 最大的区别）：
#    edge-tts 7.2.8 的依赖是下面这四行，全是纯 python 或早已装好的东西，
#    不碰 numba/llvmlite，动不到 numpy，也就动不到 mediapipe 和 cam 模式。
#    换句话说：装了不满意，`pip uninstall edge-tts` 就干净回去了，
#    不会留下"摄像头打不开"这种要命的后遗症。
#
# ⚠️ 代价是**要联网**：它走的是 Edge 浏览器"朗读"那个公开接口，免费、不要 key，

#    在线这一路失败时**自动退回 SAPI** 把这一句念完，并把这句和原因一起
#    写进 status（界面上看得见）。**"断网也一定有声音"是这一路的底线。**
